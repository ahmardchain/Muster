# Launch post drafts

**Main post**

New Mezo apps keep hearing the same thing: "every user so far is your own wallet."

Muster fixes that. Apps post quests in MUSD, users do the action on @MezoNetwork, and a contract checks their wallet and pays them. No screenshots, no reviewers.

Live on Mezo testnet 👇
https://muster.ahmardchain.workers.dev

**Reply 1**

How it works:
1. An app escrows MUSD for a quest. It goes straight into Mezo's MUSD savings vault.
2. You join first. Wallets that already qualify can't join.
3. You open a loan or save MUSD on Mezo.
4. You claim. The contract reads your wallet and pays you.
