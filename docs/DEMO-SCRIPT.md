# Demo video script (1:40)

Voiceover by ElevenLabs (voice "Jezza"), captions burned in, screens from the live site and the Mezo testnet explorer.

| Time | Screen | Narration |
|---|---|---|
| 0:00 | Home page | In Wave 1 of this buildathon, the Mezo judge told dozens of teams the same thing: every user so far is your own wallet. Muster is how Mezo apps get real users, paid in MUSD and proven on-chain. |
| 0:14 | Quest list | Muster is a quest board for Mezo. An app posts a quest, like open a MUSD loan, or save fifty MUSD in Mezo savings, and puts MUSD behind it. Anyone who does it gets paid. |
| 0:25 | Post a quest form | Posting takes one form: the action, the reward, and how many wallets to pay. The whole reward goes straight into Mezo's MUSD savings vault, so idle escrow earns yield. That yield is Muster's revenue. Quest creators pay no fee. |
| 0:40 | Quest page, then the demo wallet: join, open a loan, claim | A user joins first, then does the action. Muster refuses to let a wallet join if it already qualifies, so apps only pay for new usage. To claim, the contract reads the wallet on Mezo, its trove in the TroveManager or its sMUSD balance, and pays out of the savings vault. No screenshots, and no one reviewing them. |
| 1:02 | Explorer: verified contract | This is live on Mezo testnet. The contract is verified on the explorer, has no owner, and cannot be paused or upgraded. |
| 1:10 | Explorer: claim token transfers | Here is a quest being posted, a wallet joining, and a test claim paid out of sMUSD, all on-chain. |
| 1:17 | What it proves / What's next | Muster proves a wallet did the action after joining. It does not prove the person stayed, so rewards should be priced with that in mind. Next: outside Mezo teams posting quests, templates for the stability pool, liquidity and veBTC, and a capped mainnet launch. |
| 1:34 | End card | Muster. Real users for Mezo apps, paid in MUSD, proven on-chain. |
